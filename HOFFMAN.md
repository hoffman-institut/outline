# Outline — сборка Института Хоффмана

Исходники Outline с доработками для https://wiki.hoffman-institut.ru. Развёртывание, бэкапы и сервер описаны в репозитории `hoffman-institut/hoffman-wiki`.

## Что изменено относительно Outline

Каждая доработка — отдельный коммит поверх импорта исходников (`git log`):

- **Русский интерфейс**: язык `ru_RU`, перевод `shared/i18n/locales/ru_RU/translation.json`, русские даты.
- **Поиск с русской морфологией**: в коде `russian` вместо `english`. Функции поиска в базе данных переключает `deploy/ru-search.sh` из hoffman-wiki — запускать после каждого обновления.
- **«Архив»** для раздела (i18n-контекст `section`), «Архивировать» — для действия.
- **Страница входа**: заголовок в две строки и описание, вход по почте первым, служебный вход (Dex) — ссылкой «Только для администратора».
- Перевод кэшируется в браузере на час, а не на неделю; у адреса перевода есть версия (хеш файлов перевода), поэтому после выката новые строки видны сразу.
- **Блок «База данных»** (`/база`): столбцы с типами, цветные теги, виды «Таблица», «Доска», «Календарь», сортировка и фильтры, страница строки. Хранится в документе, в markdown — блок `hoffman-database`. Подробно — `HOFFMAN-DATABASE.md`.
- **Колонки** (`/колонки`): блок из 2–3 колонок (`shared/editor/nodes/Columns.ts`), в markdown — `%%%%columns` / `%%%column` … `%%%` / `%%%%`. На телефоне колонки идут одна под другой.
- **Цвет текста**: кнопка «Цвет текста» в панели форматирования, 7 цветов и свой (`shared/editor/marks/TextColor.ts`), в markdown — `{color:#E03E3E}текст{/color}`.
- **Отступы по Tab**: Tab сдвигает абзац (заголовок, блок) вправо, Shift+Tab и Backspace в начале строки — обратно, до 6 уровней; Enter сохраняет отступ. Это блок-обёртка `indent` (`shared/editor/nodes/Indent.ts`), он последний в списке узлов, поэтому списки, таблицы, код и раскрывающиеся блоки получают Tab раньше. В markdown отступов нет: при переписывании документа через API/MCP они пропадают.
- **Поиск эмодзи по-русски**: `shared/utils/emojiRu.json` — русские ключевые слова emojibase-data 16 (MIT) для id emoji-mart, грузится отдельным файлом.
- **Карточки Яндекс Диска и Nextcloud**: публичная ссылка `disk.yandex.ru/i|d/…` или `cloud.hoffman-institut.ru/s/…`, вставленная как встраивание, показывает картинку, видео, файл или первые 12 файлов папки. Оба сервиса запрещают показ во фрейме, поэтому карточку рисует сервер wiki (`/embeds/files`, `server/routes/fileCards.ts`) по их API: Яндекс — `cloud-api.yandex.net/v1/disk/public/resources`, Nextcloud — PROPFIND `public.php/webdav` с токеном ссылки. Запросы идут только к этим двум адресам и только для вошедших пользователей; настройки Nextcloud не менялись. Ссылки с паролем и удалённые показываются карточкой «нет доступа».
- **MCP для баз**: инструменты `list_databases`, `query_database`, `add_database_row`, `update_database_row`, `delete_database_row` (`server/mcp/tools/databases.ts`) — Claude читает и меняет строки баз, не переписывая документ. Общая логика с REST `databases.*` — `server/utils/databaseRows.ts`.

## Версия редактора

`shared/editor/version.ts` (`EDITOR_VERSION`) поднимается на **major** при каждом новом типе блока или другом несовместимом изменении схемы редактора. Сервер совместного редактирования не пускает клиентов с меньшим major. Иначе браузер со старым закэшированным интерфейсом не знает нового блока и удаляет его из документа: так 03.11.2026 пропала база «Дни рождения». То же для новых полей и типов столбцов базы: `normalizeDatabase` старого клиента их выбрасывает и при правке стирает. История: 18.0.0 — блок «База данных», 19.0.0 — итоги, 20.0.0 — формулы, 21.0.0 — связи и сводки, 22–25 — h9–h12 (автономер, группы фильтров, формы и шаблоны, время и файлы), 26.0.0 — связанная база (новый узел), 27.0.0 — колонки, отступы, цвет текста. При обновлении Outline взять `max(upstream, наш) + 1`.

## Проверки

На каждую отправленную ветку GitHub Actions проверяет типы и запускает тесты (`.github/workflows/check.yml`). Ветки `feature/*` собирают образ `dev-<sha>` для стенда, см. `HOFFMAN-DATABASE.md`.

## Сборка

Образ собирает GitHub Actions (`.github/workflows/image.yml`) по тегу вида `v<версия Outline>-h<номер>`:

```bash
git tag v1.11.0-h2 && git push origin v1.11.0-h2
```

Результат — `ghcr.io/hoffman-institut/outline:1.11.0-h2`. Сборка идёт 30–60 минут и проверяет, что доработки попали в образ.

## Выкатка

На сервере wiki (`ssh hoffman-mattermost`, `/root/outline`):

1. `/root/backup_outline.sh`
2. В `docker-compose.yml` поменять тег образа.
3. `docker-compose pull outline && docker-compose up -d outline`
4. `./ru-search.sh`
5. Проверить `/_health`, страницу входа, русский интерфейс, поиск.

Откат — прежний тег в `docker-compose.yml` и `docker-compose up -d outline`.

## Обновление Outline

1. Новая ветка с импортом новой версии: `git fetch https://github.com/outline/outline.git tag v<X> --depth 1` и коммит её дерева «Import Outline v<X>».
2. Перенести поверх коммиты Хоффмана (`git cherry-pick`), разрешить конфликты.
3. Дополнить перевод новыми строками из `shared/i18n/locales/en_US/translation.json`.
4. Тег `v<X>-h1` → сборка → выкатка по шагам выше.
